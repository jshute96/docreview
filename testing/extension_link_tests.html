Extension "Open in Docreview" Context Menu — Manual Test

This page is for manually testing the "Open in Docreview" right-click context menu item added by the Docreview Chrome extension. Context menus are native browser UI and cannot be tested in automated Playwright tests.

How to test: Load the extension, open this page, and right-click each link below. "Open in Docreview" should appear in the context menu for links marked should show and should NOT appear for links marked should not show.

Google Docs (should show)

  • Google Doc — should show
  • Google Sheet — should show
  • Google Slides — should show
  • Google Doc (http) — should show

Google Drive (should show)

  • Drive file — should show
  • Drive open link — should show
  • Drive file (http) — should show

Public shorteners (should show)

  • bit.ly link — should show
  • tinyurl.com link — should show
  • t.co link — should show
  • bit.ly (http) — should show

Non-matching links (should NOT show)

  • Google homepage — should not show
  • Drive folder (no doc ID) — should not show
  • Google Forms — should not show
  • GitHub link — should not show
  • Plain website — should not show
